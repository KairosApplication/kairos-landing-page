# 🏪 Kairos — Gestão Inteligente de Mercados

Plataforma web para gerenciamento de produtos, estoque e reposição em supermercados, com mapa interativo, relatórios de IA e alertas em tempo real.

## 📋 Funcionalidades

- **Mapa do Mercado** — Visualização interativa das gôndolas com informações ao vivo
- **Relatório de IA** — Relatórios mensais com retrospecto do mercado
- **Alertas em Tempo Real** — Notificações sobre prateleiras vazias e reposição
- **Integração da Equipe** — Controle colaborativo para repositores
- **Cadastro de Produtos** — Registro simplificado de itens

## 🗂️ Estrutura do Projeto

```
InterDisciplinar/
├── Inter.html          # Página inicial (landing page)
├── Inter.css           # Estilos da página inicial
├── Inter.js            # Carrosséis e interatividade
├── login.html          # Página de login
├── Logins.css          # Estilos do login
├── Login.js            # Alternar visibilidade da senha
├── Cadastro.html       # Cadastro (etapa 1: nome, e-mail, senha)
├── Cadastro.css        # Estilos do cadastro etapa 1
├── Cadastro1.html      # Cadastro (etapa 2: data, CPF, CEP)
├── Cadastro1.css       # Estilos do cadastro etapa 2
├── Assets/             # Ícones, logotipos e ilustrações SVG
├── Informações/dados   # Pasta de destino do formulário de login
├── kairos-landing-page/# Projeto auxiliar (landing page alternativa)
└── README.md           # Este arquivo
```

## 🚀 Como Usar

1. Abra o arquivo `Inter.html` em qualquer navegador moderno.
2. Navegue pelas seções: Funcionalidades → Passo a Passo → Mapa → Benefícios → Valores.
3. Clique em **"Entrar"** para acessar a tela de login ou cadastro.
